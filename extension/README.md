# Ready-to-load AIRE extension

This folder is the built extension. Chrome loads it directly. Don't edit
anything here: it's rebuilt automatically from the source code on every
update to the main branch.

To install: open `chrome://extensions`, turn on **Developer mode**, click
**Load unpacked** and choose **this folder** (the one containing
`manifest.json`).

Full instructions are in the main README, under "For testers".
